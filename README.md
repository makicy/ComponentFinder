# Component Finder

Unityシーン内から、指定したコンポーネント付きの
オブジェクトを検索できるEditor拡張ツールです。

「コンポーネントがどこに付いているのか分からない」
「コンポーネント付きのオブジェクトをまとめて確認したい」

このような場面で、複数のコンポーネントを選択し、
VRChatワールド制作やアバター改変に限らず利用できます。

大きくなったシーン内の確認作業や、設定漏れの確認作業を効率化できます。


# 主な機能

・対象のコンポーネントを複数選択
・複数条件によるオブジェクト検索
・検索結果を一覧で表示
・対象オブジェクトを選択
・対象オブジェクトをピン留め
・ピン留めしたオブジェクトの選択状態を保持
・ピン留めした複数オブジェクトの一括選択
・検索履歴からコンポーネントを再選択
・検索結果の全選択、および選択解除
・EditorWindow形式のシンプルなUI


# 想定用途

・設定漏れの確認
・不要なコンポーネントの確認
・シーン内、オブジェクトの整理作業
・複数オブジェクトの一括編集
・VRChatワールド制作時のコンポーネント確認
・Collider、Renderer、UdonBehaviourなどの検索
・特定条件に一致するオブジェクトの洗い出し


# 導入方法

1. Unityプロジェクトに本ツールをインポートします
2. Unity上部メニューから "Tools/RiccaLab/Finder" を開きます
3. 検索したいコンポーネントを選択します
4. 必要に応じて、複数のコンポーネントを条件として追加します
5. 検索結果から対象のオブジェクトを確認できます
6. ピン留め機能を使うことで、対象オブジェクトをまとめて選択・編集できます


# 注意事項

・本ツールはUnity Editor上で動作するEditor拡張です
・VRChat内やビルド後のワールド内では動作しません
・検索対象は現在開いているシーン内のオブジェクトです
・非表示オブジェクトも検索対象に含まれます
・ピン留め機能は、Unity Editor上で対象オブジェクトの選択状態を扱うための補助機能です
・Unityのバージョンやプロジェクト環境によって、表示や動作が異なる場合があります
